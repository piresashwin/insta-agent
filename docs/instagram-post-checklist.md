# Instagram post checklist — views + follower value

Use when reviewing drafts (`pending_approval`) or generated media before approve.
Score each item **pass / fail**. Fail on the 10-second gate → revise before publish.

Pipeline coverage (what generation enforces vs misses): [`instagram-post-checklist-audit.md`](./instagram-post-checklist-audit.md).

Sources (2025 practices): Instagram Creators (Reels distribution / watch signals), Hootsuite Reels tips, SocialPilot format trends, carousel save/share guides (Maeve, Hootsuite, carousel studies).

## Universal (every format)

- [ ] **One job** — educate *or* entertain *or* make them feel seen (not all three)
- [ ] **Specific audience** — named problem, not a vague crowd
- [ ] **Hook = promise** — curiosity or pain; works in preview / first 1–3s alone
- [ ] **Value without the caption** — stranger gets a usable takeaway from the visual alone
- [ ] **CTA matches format** — save / share / try this / real comment (not empty bait)
- [ ] **Truth test** — hook delivers; no clickbait

## Feed (single image)

**Best for:** one insight, proof, myth-bust, product/scene  
**Signals:** saves, comments, profile visits

- [ ] On-image: **≤12 words**, restrained type (~5–7% of frame height per line; block &lt; ~22% of frame)
- [ ] Visual **shows** the tip (framework, before/after, checklist) — not only lifestyle stock + opinion
- [ ] Caption: hook → short context → **one** actionable tip → question or save CTA
- [ ] First caption line works before “more”

**Fail pattern:** pretty photo + vague opinion; teachable content only in caption.

## Reel

**Best for:** discovery / non-followers  
**Signals:** watch time, retention, low skip in first 3s, shares

- [ ] **0–3s hook** on-screen + spoken/visual change (problem, bold claim, or result first)
- [ ] Tip starts **immediately** — no long intro
- [ ] New visual or text beat every **1–2s**
- [ ] One idea; end with clear payoff + soft CTA
- [ ] Length intentional — one 6–15s clip (shortest length that lands the idea), no padding

## Carousel

**Best for:** depth, tutorials, “save for later”  
**Signals:** swipe-through, saves, shares

- [ ] **Slide 1:** hook + promise (not logo / soft quote) — ~6–10 words
- [ ] **One idea per slide**; readable in ~3–5s
- [ ] Flow: Hook → why it matters → steps → mistake/trap → recap → CTA
- [ ] **Last slide:** one-line takeaway + Save / Share with ___ (not a blank logo card)
- [ ] No filler slides — every swipe teaches or advances

## 10-second gate (before approve)

1. Would I stop scrolling?
2. Do I learn something **without** opening the caption?
3. Would I save this or send it to someone with the same problem?

If any answer is **no** → revise hook or change format (often: feed opinion → carousel steps / Reel demo).
