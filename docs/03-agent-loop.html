Week 1 · Lesson 03

Agent loop

ReAct lite: plan → act → observe → stop. This is cognition — not persistence yet.

Time · 1 day
Learn
  • What a tool is (vs skill / model / side effect)
  • Good tools vs bad tools (artifacts vs god-tools / publish / mush)
  • How tool parameters are known: prompt descriptions + tool-side validation (not magic)
  • Who calls tools: the loop executes; the model only chooses
  • Tool registry and observation normalizer
  • Stop conditions: success, error, max steps, timeout
  • Why budgets are part of architecture, not niceties
Build
  1. In-process loop with two tools: content_planning, finish(draft)
  2. Hard limits: MAX_STEPS=8, TIMEOUT_MS=60000
  3. Print every step to the console
Checkpoint

You can watch the model choose tools. Killing the process mid-run corrupts nothing external (there is no world API yet).

Detailed lesson

Full explanations: what a tool is, good vs bad, how args are known, who calls tools, pipeline vs loop, budgets, pseudo code — The agent loop (deep dive) (especially §4.6–4.7).

Four notes
  • What problem does this layer solve?
  • What is allowed to call it?
  • What must it never do?
  • How do I observe and test it?
