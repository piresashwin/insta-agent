Gated publish

One orchestrated publish path: policy + approval + media ready → Graph create/publish with backoff.

Time · 1–2 days
Learn
  • Idempotency keys; 429 backoff
  • Container create vs publish steps
  • Map Graph errors to known failed state
  • Append to learn/posts.json after success
Build
  1. Collapse stub step endpoints into one publish
  2. Require copy approve + Approve media (R2) + policy allow
  3. Audit event on success/failure; never leave status unknown
Checkpoint

Publish denied unless status is staged with R2 HTTPS URLs. Success or failed with a reason.

Built in this repo
  • POST /approve-media — bake PNGs → Cloudflare R2 → staged
  • POST /publish-instagram — human only; requires staged
  • Carousel: Graph children + parent CAROUSEL
  • Status: staged → pending_upload → publishing → published|failed
  • Agent publish still denied by policy
