Built in this repo

Dashboard reads/writes only via client/src/api.ts (no demo posts). Vite proxies /api → :3001; optional VITE_API_URL. Queue filter uses GET /api/posts?status=. Refresh reloads from SQLite. Accounts tab = /api/admin/instagram. HITL actions (approve / request-changes / restart / iterations) stay server-owned. Accounts tab: add / disconnect / remove via /api/admin/instagram (status configured until Lesson 14 OAuth).

Four notes
